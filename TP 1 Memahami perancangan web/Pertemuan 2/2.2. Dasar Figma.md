## 1. Membuat Akun dan Masuk ke Figma

Figma adalah aplikasi desain berbasis *cloud* (dapat diakses langsung melalui browser maupun aplikasi desktop).

### Langkah-langkah Memulai:
1. **Akses Situs Resmi**: Buka browser dan kunjungi [https://www.figma.com](https://www.figma.com).
2. **Pendaftaran (Sign Up)**:
   * Klik tombol **Get Started** atau **Sign Up** di pojok kanan atas.
   * Pilih **Continue with Google** untuk cara cepat menggunakan akun Google.
3. **Konfirmasi Profil**:
   * Isi nama lengkap dan tujuan penggunaan.
4. **Masuk ke Dashboard**:
   * Setelah berhasil login, Anda akan masuk ke halaman utama (*Drafts / Recent Files*).
   * Untuk membuat lembar kerja baru, klik tombol **+ Design file** di pojok kanan atas.

## 2. Mengenal Toolbar dan Panel Kiri (Layers & Assets)

Antarmuka kerja Figma terbagi menjadi beberapa bagian utama:

![alt text](/Media/figma.png)
```
Panel Kiri
    - layers
    - assets
    - pages
Panel Kanan
    - design
    - prototype
    - inspect
Toolbar (tengah bawah)
    - tools
Canvas (tengah)
    - area kerja
```

### A. Toolbar (tengah bawah)
Toolbar berisi alat-alat utama untuk membuat dan memanipulasi elemen desain:

* **Move Tool (`V`)**: Memindahkan dan memilih objek di canvas.
* **Scale Tool (`K`)**: Mengubah ukuran objek secara proporsional beserta stroke & teks.
* **Frame Tool (`F`)**: Membuat kanvas/artboard dengan ukuran standar (HP, Tablet, Desktop).
* **Shape Tools (`R`, `O`, `L`)**: Alat membuat bentuk geometri dasar (*Rectangle*, *Ellipse*, *Line*).
* **Pen Tool (`P`)**: Menggambar bentuk kustom/vektor secara bebas.
* **Text Tool (`T`)**: Menambahkan teks ke canvas.
* **Comment (`C`)**: Memberikan umpan balik / catatan kolaborasi di area desain.

### B. Panel Kiri
Panel kiri berisi manajemen struktur dokumen Anda:

1. **Pages**:
   * Mengelompokkan lembar kerja dalam satu file project.
   * *Contoh*: `Page 1: Wireframe`, `Page 2: Final Design`, `Page 3: Component System`.
2. **Layers (Lapisan)**:
   * Menampilkan daftar urutan hierarki seluruh objek, frame, teks, dan grup.
   * **Aturan Layer**: Objek yang berada di urutan **paling atas** pada daftar layer akan **menutupi** objek di bawahnya.
3. **Assets**:
   * Tempat menyimpan komponen yang dapat digunakan berulang kali (*reusable components*).

## C. Panel Kanan (Design, Prototype, Inspect / Dev Mode)

Panel kanan sifatnya dinamis dan menyesuaikan dengan objek yang sedang diklik/dipilih. Terdiri dari 3 tab utama:

### 1. Tab Design
Digunakan untuk mengatur properti visual dari objek yang dipilih:
* **Alignment**: Meratakan objek (Rata kiri, tengah, kanan, atas, bawah).
* **Position & Size**: Koordinat `X`, `Y`, Lebar `W`, Tinggi `H`, dan Sudut `Rotation`.
* **Corner Radius**: Mengatur kebulatan sudut objek.
* **Fill**: Mengubah warna latar (Solid, Gradient, Gambar).
* **Stroke**: Mengatur garis tepi (Warna, Ketebalan, Posisi garis).
* **Effects**: Menambahkan efek visual (*Drop Shadow*, *Layer Blur*).
* **Export**: Mengunduh elemen desain dalam format PNG, JPG, SVG, atau PDF.

### 2. Tab Prototype
Digunakan untuk membuat simulasi interaksi antar halaman:
* Menghubungkan frame A ke frame B menggunakan *noodle connector*.
* Mengatur triger interaksi (*On Click*, *On Hover*, *On Drag*).
* Mengatur animasi transisi (*Instant*, *Dissolve*, *Smart Animate*).

### 3. Tab Inspect / Dev Mode (`Shift + D`)
Digunakan oleh pengembang (*developer*) untuk menerjemahkan desain menjadi kode:
* Melihat spesifikasi ukuran, warna (HEX/RGB), dan jarak margin/padding.
* Mengambil potongan kode siap pakai dalam format CSS, iOS Swift, atau Android XML.

## D. Navigasi Canvas: Zoom, Pan, dan Shortcut

### 1. Zooming (Memperbesar & Memperkecil Tampilan)
* **Menggunakan Mouse**: Tahan `Ctrl` + Scroll Roda Mouse ke Atas / Bawah.
* **Menggunakan Keyboard**: Tekan tombol `+` (Zoom In) atau `-` (Zoom Out).
* **Zoom to Fit (`Shift + 1`)**: Menampilkan seluruh objek di layar canvas.
* **Zoom to Selection (`Shift + 2`)**: Zoom langsung ke objek yang sedang dipilih.

### 2. Panning (Menggeser Canvas)
* **Menggunakan Spacebar**: Tahan `Spacebar` + Klik & Drag Mouse.
* **Menggunakan Mouse**: Klik & tahan Roda Mouse (*Middle Click*) lalu geser.
* **Hand Tool (`H`)**: Pilih Hand Tool di toolbar lalu geser canvas.
