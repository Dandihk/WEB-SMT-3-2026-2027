
## 🧪 Latihan Praktikum Mandiri

1. **Buatlah sebuah Main Component Tombol**:
   * Buat Frame ukuran `120 x 40 px`, beri warna background biru (`#2F80ED`), *Corner Radius* `8px`.
   * Tambahkan teks **"Submit"** di tengah frame.
   * Ubah Frame tersebut menjadi **Main Component** (`Ctrl + Alt + K`) dan beri nama `Button/Primary`.
2. **Buat 3 Instance Tombol**:
   * Duplikasi Main Component sebanyak 3 kali (`Ctrl + D`).
   * Gunakan teknik **Overrides** untuk mengganti isi teks pada masing-masing Instance menjadi:
     * Instance 1: **"Simpan"**
     * Instance 2: **"Batal"** (Ubah warna fill menjadi Merah `#EB5757`)
     * Instance 3: **"Kirim Data"**
3. **Uji Coba Master Update**:
   * Ubah *Corner Radius* pada **Main Component** dari `8px` menjadi `20px`.
   * Amati apa yang terjadi pada ketiga Instance tombol tersebut!



## 🧪 Latihan Praktikum Mandiri

1. **Buat 2 Buah Frame**:
   * Frame 1 (Halaman Beranda): Berisi tombol "Buka Detail".
   * Frame 2 (Halaman Detail): Berisi deskripsi lengkap dan tombol "Kembali".
2. **Atur Interaksi**:
   * Hubungkan tombol "Buka Detail" di Frame 1 ke Frame 2 menggunakan **Trigger: On Click** dan **Action: Navigate To**.
   * Pilih jenis transisi **Smart Animate** atau **Slide In (From Right)** dengan durasi `300ms` (*Ease Out*).
   * Hubungkan tombol "Kembali" di Frame 2 ke Frame 1 dengan **Action: Back**.
3. **Uji Simulasi**:
   * Tekan `Shift + Space` (Inline Preview) dan uji coba klik tombol tersebut!
