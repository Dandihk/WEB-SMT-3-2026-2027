## Tujuan
Setelah menyelesaikan aktivitas ini, peserta didik mampu **mengevaluasi kualitas sebuah website** secara kritis berdasarkan konsep dasar perancangan web, aspek *User Interface* (UI), dan *User Experience* (UX).

## Alat dan Bahan
1. Laptop / Personal Computer (PC)
2. Web Browser (Google Chrome, Firefox, Edge, atau Safari)
3. Koneksi Internet
4. Text Editor (atau Google Docs / MS Word)

## Langkah Kerja
1. **Pilih satu website** bertema bebas (contoh: website sekolah, profil perusahaan, toko online, atau instansi pemerintah).
2. **Buka website** tersebut melalui web browser pada perangkat Anda.
3. **Amati secara detail** struktur halaman utama (*homepage*) serta navigasinya.
4. **Isi tabel penilaian** di bawah sesuai hasil pengamatan Anda.
5. **Jawab pertanyaan analisis** pada bagian UI dan UX.
6. **Berikan ulasan** berupa kelebihan, kekurangan, serta saran perbaikan konkret.
7. **Presentasikan** hasil review Anda di depan kelas.
