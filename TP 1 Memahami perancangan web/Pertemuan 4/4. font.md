# Tipografi Web: Memahami Perbedaan Satuan PX, EM, dan REM

## Kompetensi Dasar

Setelah mempelajari materi ini, peserta didik mampu:
- Menjelaskan perbedaan antara satuan absolut dan relatif dalam CSS.
- Menganalisis cara kerja satuan ukuran `px`, `em`, dan `rem`.
- Menerapkan satuan yang tepat untuk ukuran font, padding, dan margin agar halaman web bersifat responsif dan aksesibel.

---

# Pendahuluan

Saat mendesain halaman web dengan CSS, menentukan ukuran teks (*font size*) adalah hal dasar yang sangat krusial. CSS menyediakan berbagai macam satuan ukuran, yang dibagi menjadi dua kategori utama:

1. **Satuan Absolut (Absolute Units)**: Ukurannya tetap dan tidak berubah dalam kondisi apa pun (Contoh: `px`, `cm`, `pt`).
2. **Satuan Relatif (Relative Units)**: Ukurannya berubah-ubah secara dinamis tergantung pada elemen acuan lainnya (Contoh: `rem`, `em`, `%`, `vw`, `vh`).

Memahami kapan harus menggunakan `px`, `em`, atau `rem` sangat menentukan apakah website yang kita buat ramah pengguna (*user-friendly*) dan responsif di berbagai ukuran layar.

---

# 1. PX (Pixel)

`px` adalah satuan absolut yang paling populer dan paling mudah dipahami. 1 pixel mewakili 1 titik fisik pada layar perangkat.

* **Cara Kerja**: Jika Anda mengatur `font-size: 16px;`, maka teks tersebut akan selalu berukuran 16 pixel di layar mana pun.
* **Karakteristik**:
  - Ukurannya konstan dan kaku.
  - Sangat mudah digunakan untuk tata letak yang membutuhkan presisi tinggi.
* **Kekurangan**:
  - **Tidak Responsif & Tidak Aksesibel**: Jika pengguna memperbesar ukuran teks bawaan di pengaturan browser mereka (misalnya karena gangguan penglihatan), teks berukuran `px` **tidak akan ikut membesar**. Ini buruk bagi aksesibilitas (*web accessibility*).

---

# 2. EM

`em` adalah satuan relatif yang acuannya adalah **ukuran font dari elemen induknya (parent element)**.

* **Cara Kerja**: 
  - Jika ukuran font parent adalah `16px`, maka `1em` pada elemen anak (*child*) akan bernilai `16px`.
  - Jika `font-size: 2em;`, ukurannya menjadi `32px` ($2 \times 16px$).
* **Karakteristik**:
  - Mengikuti ukuran induk terdekat.
  - Sangat baik digunakan untuk komponen modular yang skalanya harus proposional dengan teksnya (seperti tombol/padding tombol).
* **Masalah Efek Berantai (Compounding Effect)**:
  Jika elemen bersarang (*nested*), ukuran `em` akan terus mengalikan ukuran induknya secara berantai.
  
  *Contoh:*
  ```html
  <div style="font-size: 16px;"> <!-- Parent (16px) -->
      <div style="font-size: 1.5em;"> <!-- Child 1: 1.5 x 16px = 24px -->
          <div style="font-size: 1.5em;"> <!-- Child 2: 1.5 x 24px = 36px! -->
              Teks ini berukuran 36px!
          </div>
      </div>
  </div>
  ```

---

# 3. REM (Root EM)

`rem` adalah satuan relatif yang acuannya **hanya pada satu tempat**, yaitu ukuran font dari **Root Element (`<html>`)**.

* **Cara Kerja**:
  - Secara default, sebagian besar browser menggunakan ukuran font root sebesar `16px`.
  - Jadi, jika Anda menulis `1rem`, nilainya setara dengan `16px`.
  - `1.5rem` = `24px` ($1.5 \times 16$).
  - `2rem` = `32px` ($2 \times 16$).
* **Karakteristik**:
  - Konsisten di seluruh halaman web karena tidak terpengaruh oleh elemen parent (menghindari masalah efek berantai pada `em`).
  - **Sangat Ramah Aksesibilitas**: Jika pengguna mengubah ukuran font default browsernya menjadi `20px`, maka secara otomatis `1rem` akan bernilai `20px`, dan seluruh teks di web Anda yang menggunakan satuan `rem` akan ikut membesar secara proporsional.

---

# Tabel Perbandingan Satuan

| Kriteria | PX (Pixel) | EM | REM (Root EM) |
| :--- | :--- | :--- | :--- |
| **Sifat** | Absolut (Tetap) | Relatif (Berubah) | Relatif (Berubah) |
| **Acuan Ukuran** | Titik layar fisik | `font-size` Elemen Induk (Parent) | `font-size` Root (`<html>`) |
| **Terpengaruh Nesting?** | Tidak | **Ya** (Efek berantai mengalikan) | Tidak |
| **Aksesibilitas Browser** | Buruk | Sangat Baik | Sangat Baik (Paling Direkomendasikan) |
| **Cocok Untuk** | Border, Bayangan (*shadow*), Layout presisi tetap | Padding/Margin komponen modular | Ukuran font utama teks website, Tata letak responsif |

# Contoh Implementasi Kode

Mari perhatikan perbedaan perilakunya di dalam CSS berikut:

```css
/* Menentukan Root Font Size */
html {
    font-size: 16px; /* Bawaan browser, bisa diubah */
}

/* Menggunakan PX */
.title-px {
    font-size: 32px; /* Selalu 32px */
}

/* Menggunakan REM */
.title-rem {
    font-size: 2rem; /* 2 x 16px = 32px (Akan ikut membesar jika root berubah) */
}

/* Penggunaan EM untuk Padding Komponen */
.button-custom {
    font-size: 1rem; /* 16px */
    padding: 0.5em 1em; /* Atas-bawah 8px, Kanan-kiri 16px */
    /* Jika font-size tombol diubah ke 2rem (32px), padding otomatis ikut membesar proporsional menjadi 16px dan 32px */
}
```

---

# Rangkuman Singkat & Aturan Praktis (Rule of Thumb)

Untuk membuat website yang modern, responsif, dan rapi:
1. **Gunakan `rem`** untuk hampir semua **ukuran teks** (`font-size`) di website Anda.
2. **Gunakan `em`** untuk **padding** dan **margin** di dalam komponen khusus (seperti tombol atau kartu) agar komponen tersebut membesar secara proporsional jika ukuran font internalnya berubah.
3. **Gunakan `px`** hanya untuk elemen-elemen kecil yang ukurannya harus mutlak presisi, seperti ukuran ketebalan garis tepi (`border: 1px solid black`) atau radius sudut (`border-radius: 8px`).
