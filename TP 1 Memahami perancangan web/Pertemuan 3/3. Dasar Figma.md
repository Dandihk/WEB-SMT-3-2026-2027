## 🎯 Tujuan Pembelajaran

Setelah mengikuti modul pembelajaran ini, peserta didik diharapkan mampu:

3. Membuat dan mengatur **Frame/Artboard** dengan preset ukuran perangkat yang responsif.
4. Membuat objek geometri dasar (*Rectangle, Ellipse, Polygon, Star*) dan memanipulasi propertinya.
5. Menggunakan **Pen Tool** dan mengedit titik nodus (*Vector Editing*) untuk membuat bentuk kustom.
6. Menerapkan operasi gabungan bentuk (**Boolean Operations**: *Union, Subtract, Intersect, Exclude*).
7. Mengatur elemen **Tipografi & Teks** (hirarki visual, *line height*, *letter spacing*, *alignment*, dan *text resizing behavior*).

## 🛠️ MODUL 1: Mengenal Antarmuka (Interface) Figma

Figma adalah aplikasi *cloud-based UI/UX design* dan *prototyping* yang berjalan secara lansung melalui browser maupun aplikasi desktop. Figma memungkinkan kolaborasi secara *real-time*.

---

### 1.1 Membuat Akun dan Masuk ke Figma

1. **Buka Browser**: Akses situs resmi Figma di [https://www.figma.com](https://www.figma.com).
2. **Registrasi (Sign Up)**:
   * Klik tombol **Get started** di pojok kanan atas.
   * Gunakan akun Google (*Sign up with Google*) untuk mempermudah akses atau masukkan email & kata sandi baru.
   * Isi kuesioner singkat (Pilih peran sebagai *Student* / *Educator* jika memakai akun sekolah).
3. **Login & Dashboard**:
   * Setelah masuk, Anda akan diarahkan ke halaman **Drafts / Dashboard**.
   * Untuk membuat file baru, klik tombol **+ Design file** di pojok kanan atas.

---

### 1.2 Anatomi Antarmuka Figma

Antarmuka Figma terbagi menjadi 4 area utama:

```
+-------------------------------------------------------------------------+
| [1] TOOLBAR (Pojok Kiri Atas & Tengah)                                 |
+--------------+-------------------------------------------+--------------+
| [2] PANEL    |                                           | [3] PANEL    |
| KIRI         | [4] CANVAS (Area Kerja Utama)             | KANAN        |
| - Layers     |                                           | - Design     |
| - Assets     |                                           | - Prototype  |
| - Pages      |                                           | - Inspect    |
|              |                                           |   (Dev Mode) |
+--------------+-------------------------------------------+--------------+
```

#### 1. Toolbar Utama (Kiri Atas)
* **Main Menu (Logo Figma)**: Membuka menu file, preferensi, plugin, dan ekspor.
* **Move Tools (`V` / `K`)**:
  * **Move Tool (`V`)**: Memindahkan, menggeser, dan memilih objek.
  * **Scale Tool (`K`)**: Mengubah ukuran objek beserta stroke & font secara proporsional.
* **Frame Tool (`F`)**: Membuat container/artboard dengan ukuran standar (Desktop, Mobile, Tablet).
* **Shape Tools (`R`, `O`, `L`)**: Membuat bentuk geometris dasar.
* **Pen Tool (`P`) & Pencil Tool (`Shift + P`)**: Menggambar bentuk vektor kustom.
* **Text Tool (`T`)**: Menambahkan teks pada canvas.
* **Resources (`Shift + I`)**: Mengakses Components, Plugins, dan Widgets.
* **Hand Tool (`H`)**: Menggeser tampilan canvas tanpa memindahkan posisi objek.
* **Add Comment (`C`)**: Memberikan umpan balik/catatan kolaborasi.

---

#### 2. Panel Kiri (Left Sidebar)
* **Pages**: Mengelompokkan lembar kerja dalam satu file (contoh: *Page 1: Wireframe*, *Page 2: Final UI*, *Page 3: Design System*).
* **Layers**: Menampilkan daftar hierarki seluruh objek, frame, group, dan teks di halaman aktif.
  * *Urutan Layer*: Objek yang berada di posisi atas daftar Layer akan menutupi objek yang berada di bawahnya.
* **Assets**: Tempat menyimpan dan mengambil *Components* serta *Library* yang siap dipakai ulang.

---

#### 3. Panel Kanan (Right Sidebar)
Panel ini berubah secara dinamis tergantung pada objek yang sedang dipilih:

* **Design Tab**:
  * **Alignment**: Meratakan objek (Rata kiri, tengah, kanan, atas, bawah, *distribute spacing*).
  * **Position & Size**: Koordinat `X`, `Y`, Lebar `W`, Tinggi `H`, Sudut `Rotation`, dan *Corner Radius*.
  * **Constraints**: Menentukan perilaku posisi objek saat ukuran Frame induk diubah.
  * **Layer & Blending Modes**: Pengaturan opasitas (*Opacity*) dan efek pencampuran warna.
  * **Fill**: Mengatur warna latar (*Solid, Gradient, Image, Video*).
  * **Stroke**: Mengatur garis tepi (Ketebalan, Warna, Position: *Inside, Center, Outside*).
  * **Effects**: Menambahkan efek visual (*Drop Shadow, Inner Shadow, Layer Blur, Background Blur*).
  * **Export**: Mengunduh elemen dalam format PNG, JPG, SVG, atau PDF.

* **Prototype Tab**:
  * Digunakan untuk menghubungkan antar frame (*Interactions*) seperti *On Click, On Hover, Drag*, animasi transisi (*Smart Animate, Dissolve, Push*), dan pengujian simulasi jalannya aplikasi.

* **Inspect / Dev Mode (`Shift + D`)**:
  * Mode khusus untuk *Developer* web/mobile untuk melihat spesifikasi ukuran, warna, margin/padding, dan mengambil kode siap pakai (CSS, iOS Swift, Android XML).

---

### 1.3 Navigasi Canvas dan Shortcut Penting

Menguasai navigasi canvas akan mempercepat proses pembuatan desain secara signifikan.

#### Navigasi Dasar:
* **Zoom In / Zoom Out**:
  * Tahan `Ctrl` + Scroll Mouse ke Atas / Bawah.
  * Atau tekan `+` dan `-` pada keyboard.
  * **Zoom to Fit**: Tekan `Shift + 1` (Menampilkan seluruh objek di layar).
  * **Zoom to Selection**: Tekan `Shift + 2` (Zoom fokus pada objek yang dipilih).
* **Pan / Menggeser Canvas**:
  * Tekan & tahan `Spacebar` + Klik Drag Mouse.
  * Atau gunakan *Middle Mouse Button* (Klik Roda Mouse) lalu geser.

## 📐 MODUL 2: Bentuk dan Objek Dasar

Semua antarmuka aplikasi dibangun dari gabungan bentuk-bentuk dasar (*primitive shapes*) dan vektor.

---

### 2.1 Membuat Frame dan Artboard

**Frame** di Figma berfungsi sebagai kanvas khusus atau *container* tempat menempatkan elemen UI (seperti layar HP, Tablet, atau Desktop).

#### Perbedaan Frame vs Group:
* **Frame (`F`)**: Memiliki preset ukuran standar, dapat memiliki warna latar (*Fill*), aturan penyusunan (*Auto Layout*), *Constraints*, serta kliping konten (*Clip content*).
* **Group (`Ctrl + G`)**: Hanyalah pembungkus beberapa objek agar mudah dipindahkan bersama tanpa memiliki sifat kanvas/responsif tersendiri.

#### Cara Membuat Frame:
1. Tekan tombol `F` pada keyboard.
2. Perhatikan Panel Kanan, pilih Preset perangkat:
   * **Phone**: iPhone 14 / 15, Android Large.
   * **Tablet**: iPad Mini, iPad Pro.
   * **Desktop**: Desktop (1440 x 1024), MacBook Pro.
3. Atau klik & drag langsung di canvas untuk membuat ukuran kustom.

---

### 2.2 Shape Tools (Bentuk Dasar)

Tekan tombol `Shift + R` atau klik drop-down menu bentuk di toolbar untuk memilih:

1. **Rectangle (`R`)**:
   * Digunakan untuk membuat tombol, kartu (*card*), latar belakang, dan pembatas.
   * **Corner Radius**: Geser titik bulat (*handle*) di sudut dalam persegi untuk membuat sudut membulat (*rounded corners*).
2. **Ellipse (`O`)**:
   * Digunakan untuk foto profil (avatar), ikon indikator, atau tombol lingkaran.
   * Tahan `Shift` saat membuat lingkaran agar proporsional sempurna (1:1).
   * **Arc Handle**: Tarik titik di pinggir lingkaran untuk membuat lingkaran terpotong (*pie chart* / donat).
3. **Polygon**:
   * Digunakan untuk bentuk segitiga, segi-lima, segi-enam, dan ikon peringatan.
   * Ubah jumlah sudut (*Count*) pada panel kanan bagian *Count*.
4. **Star**:
   * Digunakan untuk ikon *rating*, *badge*, atau efek dekoratif.
   * Pengaturan: *Count* (jumlah bintang), *Ratio* (kedalaman sudut bintang), dan *Radius*.

---

### 2.3 Pen Tool & Vector Editing

**Pen Tool (`P`)** digunakan untuk membuat ikon kustom, kurva, dan ilustrasi vektor yang presisi.

1. **Membuat Garis Lurus**: Klik sekali di titik A, lalu klik di titik B.
2. **Membuat Kurva (Bézier Curve)**: Klik dan tahan mouse di titik B lalu drag untuk memunculkan *Bézier Handle*.
3. **Mengedit Vektor (Edit Object Mode)**:
   * Double-click pada objek vektor atau tekan `Enter`.
   * **Move Tool (`V`)**: Menggeser titik nodus (*anchor point*).
   * **Bend Tool (`Ctrl` / `Cmd`)**: Mengubah garis lurus menjadi kurva bergelombang.
   * **Paint Bucket (`B`)**: Mengisi warna pada area vektor yang tertutup (*Vector Network*).
   * Klik **Done** di toolbar atas jika selesai mengedit.

---

### 2.4 Boolean Operations (Operasi Penggabungan Objek)

**Boolean Operations** digunakan untuk menggabungkan dua atau lebih objek bentuk dasar menjadi satu bentuk kompleks baru.

Pilih minimal 2 objek yang saling tumpang tindih (*overlap*), lalu klik ikon **Boolean Groups** di toolbar bagian atas:

```
[ Union ]      [ Subtract ]      [ Intersect ]      [ Exclude ]
  (A + B)        (A - B)           (A ∩ B)            (A ⊕ B)
```

1. **Union Selection** (`A + B`):
   * Menggabungkan seluruh objek menjadi satu bentuk tunggal.
   * *Contoh*: Membuat ikon awan dari gabungan beberapa lingkaran dan persegi.
2. **Subtract Selection** (`A - B`):
   * Memotong objek bagian bawah menggunakan objek yang berada di paling atas.
   * *Contoh*: Membuat ikon bulan sabit (lingkaran dipotong lingkaran lain) atau ikon keranjang belanja yang berlubang.
3. **Intersect Selection** (`A ∩ B`):
   * Menyisakan hanya area tumpang tindih dari objek-objek tersebut.
   * *Contoh*: Membuat bentuk daun dari perpotongan dua lingkaran.
4. **Exclude Selection** (`A ⊕ B`):
   * Menghilangkan area yang saling tumpang tindih dan menyisakan area sisanya.

> [!NOTE]
> Operasi Boolean di Figma bersifat **Non-Destructive**. Artinya, Anda masih bisa mengedit posisi dan bentuk objek pembentuk di dalam hierarki layer Boolean kapan saja!

## 🔤 MODUL 3: Tipografi dan Teks

Tipografi adalah elemen terpenting dalam desain antarmuka web dan aplikasi. Teks yang baik memberikan informasi yang jelas, mudah dibaca, dan membangun hirarki visual.

---

### 3.1 Menambahkan Teks (`T`)

1. Tekan tombol `T` pada keyboard.
2. Klik di canvas untuk mengetik teks.
3. **Mode Text Box**:
   * **Point Text (Auto Width)**: Ukuran kotak teks melebar otomatis mengikuti panjang ketikan teks.
   * **Area Text (Fixed Size)**: Anda menentukan lebar kotak teks terlebih dahulu dengan klik & drag. Teks akan otomatis turun ke bawah (*word wrap*) jika mencapai batas lebar.

---

### 3.2 Pengaturan Properti Teks (Text Panel)

Saat objek Teks dipilih, buka **Panel Kanan (Design)** pada seksi **Text**:

* **Font Family**: Memilih jenis font (contoh: *Inter, Roboto, Poppins, Open Sans*).
* **Font Weight**: Ketebalan font (*Regular, Medium, Semi-Bold, Bold, Extra-Bold*).
* **Font Size**: Ukuran teks dalam satuan piksel (`px`).
* **Line Height (Tinggi Baris)**: Jarak vertikal antar baris teks (Rekomendasi: `130% - 150%` untuk paragraf agar nyaman dibaca).
* **Letter Spacing (Kerning/Tracking)**: Jarak antar huruf.
* **Paragraph Spacing**: Jarak spasi antar paragraf.
* **Text Resizing**:
  * `Auto Width` (↔️): Kotak mengikuti lebar teks.
  * `Auto Height` (↕️): Lebar kotak tetap, tinggi kotak menyesuaikan jumlah baris.
  * `Fixed Size` (↔️↕️): Lebar dan tinggi kotak terkunci (teks terpotong/overflow jika melebihi batas).

---

### 3.3 Prinsip Hirarki Tipografi dalam UI Design

Agar tampilan aplikasi terlihat profesional, gunakan **Typography Scale** standar:

| Level Hirarki | Ukuran Font (`px`) | Weight | Penggunaan |
| :--- | :--- | :--- | :--- |
| **Heading 1 (H1)** | 32px - 48px | Bold / Extra-Bold | Judul Utama Halaman / Hero Section |
| **Heading 2 (H2)** | 24px - 28px | Bold / Semi-Bold | Judul Seksi / Card Title |
| **Heading 3 (H3)** | 18px - 20px | Semi-Bold | Sub-judul / Title Komponen |
| **Body Large** | 16px | Regular / Medium | Teks utama paragraf web |
| **Body Medium** | 14px | Regular | Teks paragraf standar mobile |
| **Caption / Subtitle**| 12px | Regular / Medium | Label kecil, *timestamp*, keterangan gambar |

## 🧪 Latihan Praktikum Mandiri

Untuk memantapkan pemahaman materi, kerjakan latihan praktikum berikut:

### Tugas 1: Membuat Ikon Aplikasi dengan Boolean Operation
1. Buat Frame ukuran `100 x 100 px` dengan warna latar belakang biru cerah (`#2F80ED`) dan *Corner Radius* `20px`.
2. Buat objek lingkaran (`O`) dan persegi panjang (`R`).
3. Gunakan operasi **Subtract Selection** untuk membuat bentuk ikon *Moon* (Bulan) atau *Shopping Bag*.
4. Tempatkan ikon tepat di tengah frame menggunakan tombol **Align Center Vertically** dan **Align Center Horizontally**.

### Tugas 2: Membuat Komponen Card Profil Sederhana
1. Buat Frame Desktop/Mobile.
2. Tambahkan foto profil lingkaran (`O`) di bagian atas.
3. Tambahkan teks **Nama Lengkap** menggunakan font Size `20px` (Bold).
4. Tambahkan teks **Jabatan / Profesi** menggunakan font Size `14px` (Regular) warna abu-abu (`#828282`).
5. Tambahkan tombol "Follow" menggunakan **Rectangle** ber-radius `8px` dan teks rata tengah.
