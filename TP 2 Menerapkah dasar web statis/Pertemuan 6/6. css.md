## A. Apa Itu CSS? (Analogi Sederhana)

Jika **HTML** adalah kerangka atau tembok polos sebuah rumah, maka **CSS (Cascading Style Sheets)** adalah **cat dinding, gorden, lampu hias, dan tata letak perabotannya**.

Tanpa CSS, website akan terlihat polos hitam-putih dan membosankan. Dengan CSS, kita bisa:
* Mengubah warna teks dan latar belakang (*background*).
* Mempercantik bentuk font dan ukurannya.
* Mengatur tata letak agar rapi dan tidak berantakan.

## B. 3 Cara Menulis & Menyambungkan CSS ke HTML

Ada 3 cara untuk menerapkan kode CSS pada halaman HTML:

### 1. Inline CSS (Menulis Langsung di Tag HTML)
Kode CSS ditulis langsung di dalam atribut `style="..."` pada tag HTML tertentu.
* **Penggunaan:** Cocok untuk perubahan cepat pada 1 elemen saja.
* **Kekurangan:** Membuat kode HTML menjadi kotor dan sulit dirawat jika kodenya banyak.

```html
<h1 style="color: blue; text-align: center;">Judul Berwarna Biru</h1>
```

---

### 2. Internal CSS (Menulis di Dalam Tag `<style>`)
Kode CSS ditulis di dalam tag `<style>` yang diletakkan pada bagian `<head>` dokumen HTML.
* **Penggunaan:** Cocok jika website hanya memiliki 1 halaman saja.
* **Kekurangan:** Kode CSS tidak bisa digunakan ulang di halaman HTML lainnya.

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Internal CSS</title>
    <style>
        h1 {
            color: green;
            font-size: 24px;
        }
    </style>
</head>
<body>
    <h1>Judul Berwarna Hijau</h1>
</body>
</html>
```

---

### 3. External CSS (File Terpisah `.css` — ⭐ Rekomendasi Terbaik)
Kode CSS ditulis di file terpisah (misalnya `style.css`), lalu dihubungkan ke HTML menggunakan tag `<link>` di dalam bagian `<head>`.
* **Penggunaan:** Standar industri / dunia kerja.
* **Kelebihan:** Kode rapi, terorganisir, dan 1 file `style.css` bisa dipakai untuk banyak halaman web sekaligus!

```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>External CSS</title>
    <!-- Menyambungkan File External CSS -->
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1 class="judul-utama">Halo SMK TJKT!</h1>
</body>
</html>
```

```css
/* style.css (File Terpisah) */
.judul-utama {
    color: #2c3e50;
    text-align: center;
}
```

## C. Cara Menulis Kode CSS (Sintaks Dasar)

Penulisan CSS sangat simpel, terdiri dari **Selector** (elemen mana yang mau dihias) dan **Declaration** (hiasan apa yang mau diberikan):

```css
selector {
    property: value;
}
```

### Contoh Tiga Jenis Selector Utama:

```css
/* 1. Selector Tag (Mengubah SEMUA tag <body>) */
body {
    background-color: #f4f4f9;
    font-family: Arial, sans-serif;
}

/* 2. Selector Class (Mengubah elemen yang punya class="judul-utama") */
/* Pakai tanda TITIK (.) di depan nama class */
.judul-utama {
    color: #2c3e50;
    text-align: center;
}

/* 3. Selector ID (Mengubah elemen yang punya id="tombol-khusus") */
/* Pakai tanda PAGAR (#) di depan nama id */
#tombol-khusus {
    background-color: #e74c3c;
    color: white;
}
```

## D. Memahami Box Model (Jarak & Ukuran)

Setiap elemen di HTML dibayangkan sebagai sebuah **Kotak Kado**:

```text
  +-----------------------------------+
  | MARGIN (Jarak di luar kotak)      |
  |  +-----------------------------+  |
  |  | BORDER (Garis tepi kotak)   |  |
  |  |  +-----------------------+  |  |
  |  |  | PADDING (Jarak dalam) |  |  |
  |  |  |  +-----------------+  |  |  |
  |  |  |  | KONTEN (Teks/Img) |  |  |  |
  |  |  |  +-----------------+  |  |  |
  |  |  +-----------------------+  |  |
  |  +-----------------------------+  |
  +-----------------------------------+
```

* **Content:** Isi teks atau gambar.
* **Padding:** Jarak antara isi teks dengan garis tepi kotak (*ruang di dalam*).
* **Border:** Garis bingkai/tepi kotak.
* **Margin:** Jarak antara kotak tersebut dengan kotak lain di sekitarnya (*ruang di luar*).

### Contoh Kode Box Model:
```css
.kartu {
    background-color: white;
    padding: 20px;         /* Jarak dalam */
    border: 2px solid #ccc; /* Garis tepi */
    margin: 15px;          /* Jarak luar */
    border-radius: 10px;   /* Melengkungkan sudut kotak */
}
```

## E. Membuat Layout Rapi dengan Flexbox

Dahulu, membuat elemen berjejer ke samping sangat sulit. Sekarang dengan **Flexbox**, cukup beri `display: flex;` pada induk (*parent*) pembungkusnya!

```html
<!-- HTML -->
<div class="wadah-kartu">
    <div class="kartu">Kartu 1</div>
    <div class="kartu">Kartu 2</div>
    <div class="kartu">Kartu 3</div>
</div>
```

```css
/* CSS */
.wadah-kartu {
    display: flex;              /* Membuat elemen berjejer kesamping */
    justify-content: space-around; /* Jarak antar kartu otomatis seimbang */
    gap: 10px;                  /* Jarak antar kartu */
}

.kartu {
    background-color: #3498db;
    color: white;
    padding: 15px;
    border-radius: 8px;
    flex: 1;                    /* Semua kartu lebarnya sama */
    text-align: center;
}
```

## F. Latihan Praktik: Mempercantik Halaman HTML

Cobalah isi file **`style.css`** Anda dengan kode berikut untuk menghias `index.html` dari Pertemuan 5:

```css
/* Reset Margin Bawaan Browser */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    background-color: #eef2f3;
    color: #333;
    padding: 20px;
}

h1 {
    color: #1e3c72;
    margin-bottom: 10px;
}

p {
    line-height: 1.6;
    margin-bottom: 15px;
}

ul {
    background-color: white;
    padding: 20px 40px;
    border-radius: 8px;
    box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}

li {
    margin-bottom: 8px;
}

a {
    color: #e67e22;
    text-decoration: none;
    font-weight: bold;
}

a:hover {
    text-decoration: underline;
    color: #d35400;
}
```

## G. Rangkuman 

1. **CSS** digunakan untuk menghias dan mengatur tata letak HTML.
2. File CSS disambungkan menggunakan tag `<link rel="stylesheet" href="style.css">`.
3. Tiga selector utama: **Tag** (`h1`), **Class** (`.nama-class`), dan **ID** (`#nama-id`).
4. Bedakan **Padding** (jarak dalam) dan **Margin** (jarak luar).
5. Gunakan `display: flex;` untuk menyusun tata letak berjejer ke samping secara cepat.
