## A. Ringkasan Integrasi Web Statis (Trio Web)

Di pertemuan 5, 6, dan 7 kita telah mempelajari 3 komponen utama web statis:
1. **HTML (`index.html`):** Menyusun struktur teks, foto, dan tombol.
2. **CSS (`style.css`):** Mewarnai, memberi jarak, dan mengatur tata letak dengan Flexbox.
3. **JS (`script.js`):** Memberikan aksi klik dan fitur ubah tema (*Dark Mode*).

---

### 3. File `script.js`
```javascript
// Feature 1: Dark Mode Toggle
const tombolTema = document.getElementById("tombol-tema");

tombolTema.addEventListener("click", function() {
    document.body.classList.toggle("mode-gelap");
    
    if (document.body.classList.contains("mode-gelap")) {
        tombolTema.textContent = "☀️ Light Mode";
    } else {
        tombolTema.textContent = "🌙 Dark Mode";
    }
});

// Feature 2: Tombol Sapa Interaktif
const tombolSapa = document.getElementById("tombol-sapa");

tombolSapa.addEventListener("click", function() {
    alert("Halo! Terima kasih telah berkunjung ke website portofolio saya. Semoga harimu menyenangkan! 😊");
});
```

## D. Langkah Deploy Gratis ke GitHub Pages

Setelah web statis selesai dibuat di laptop, mari kita **online-kan** agar bisa dibuka oleh teman dan guru dari mana saja!

### Langkah 1: Buat Akun & Repository di GitHub
1. Buka browser dan masuk ke [github.com](https://github.com).
2. Login (atau *Sign Up* jika belum punya akun).
3. Klik tombol **`+`** di sudut kanan atas > pilih **New repository**.
4. Isi **Repository name**: `portofolio-web` (gunakan huruf kecil tanpa spasi).
5. Pilih **Public**.
6. Centang **Add a README file**.
7. Klik **Create repository**.

### Langkah 2: Upload File Proyek Anda
1. Di dalam repository yang baru dibuat, klik tombol **Add file** > pilih **Upload files**.
2. Drag & drop 3 file Anda (`index.html`, `style.css`, `script.js`) ke dalam area upload.
3. Klik tombol hijau **Commit changes**.

### Langkah 3: Aktifkan GitHub Pages (Deploy)
1. Buka tab **Settings** di bagian atas repository.
2. Di menu sebelah kiri, klik **Pages**.
3. Pada bagian **Build and deployment** > **Branch**:
   - Ubah dari `None` menjadi **`main`**.
   - Folder biarkan `/(root)`.
4. Klik tombol **Save**.

### Langkah 4: Website Anda Sudah Online! 🎉
Tunggu sekitar 1–2 menit, refresh halaman Settings > Pages. Anda akan melihat kotak hijau bertuliskan:
> **"Your site is live at https://username.github.io/portofolio-web/"**

Salin link tersebut dan bagikan ke guru atau teman Anda!
