## Pendahuluan

Setelah mempelajari perancangan dan riset web di **TP 1**, sekarang kita melangkah ke tahap mengeksekusi desain tersebut menjadi sebuah **Website Statis** yang nyata dan dapat diakses melalui browser.

Website statis adalah website yang kontennya disampaikan kepada pengguna persis seperti yang disimpan di server, tanpa memerlukan basis data (*database*) atau logika pemrograman server-side yang kompleks. Untuk membangun website statis modern yang menarik, kita menggunakan **3 Pilar Utama Pemrograman Web**:

```text
  +-----------------------------------------------------------------------+
  |                             PILAR WEB STATIS                          |
  +-----------------------------------------------------------------------+
  |  1. HTML (Structure)  ---> Menentukan struktur & kerangka konten.      |
  |  2. CSS (Styling)     ---> Mengatur tampilan visual, warna, & layout.  |
  |  3. JS (Behavior)     ---> Memberikan interaktivitas & dinamika web.  |
  +-----------------------------------------------------------------------+
```

## Capaian & Tujuan Pembelajaran (TP 2)

Setelah menyelesaikan seluruh rangkaian materi pada **TP 2 (Menerapkan Dasar Web Statis)** ini, peserta didik diharapkan mampu:

### 1. Penguasaan HTML (HyperText Markup Language)
- Menjelaskan konsep dasar web statis dan cara kerja web browser.
- Menyusun struktur dokumen **HTML5** yang standar dan valid.
- Mengaplikasikan tag-tag dasar untuk teks (*heading, paragraf, format teks*), media (*gambar, audio, video*), dan daftar (*list*).
- Membuat tabel data dan formulir (*form input*) interaktif.
- Menerapkan elemen semantik HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) untuk struktur web yang terorganisir dan ramah SEO.

### 2. Penguasaan CSS (Cascading Style Sheets)
- Memahami cara kerja selector, property, dan value dalam CSS.
- Menghubungkan CSS dengan HTML menggunakan metode *Inline, Internal,* dan *External CSS*.
- Menerapkan konsep **Box Model** (*margin, border, padding, content*).
- Mengatur tata letak halaman web menggunakan teknik modern **Flexbox** dan **CSS Grid**.
- Merancang tampilan web yang **Responsif** (dapat menyesuaikan layar HP, tablet, dan desktop) menggunakan *Media Queries*.
- Menambahkan efek visual modern (transisi, animasi mikro, gradient, dan shadow).

### 3. Penguasaan JavaScript (Interaktivitas Sisi Klien)
- Memahami konsep dasar variabel, tipe data, operator, dan fungsi dalam JavaScript.
- Mengakses dan memanipulasi elemen HTML/CSS menggunakan **DOM (Document Object Model)** Manipulation.
- Menangani interaksi pengguna melalui **Event Listener** (seperti `click`, `submit`, `input`, `hover`).
- Membangun fitur interaktif sederhana pada web statis (misal: *Toggle Dark Mode*, *Pop-up Modal*, *Validasi Form*, dan *Hamburger Navigation Menu*).

### 4. Integrasi & Publikasi Proyek Web Statis
- Menggabungkan kode HTML, CSS, dan JavaScript menjadi satu kesatuan aplikasi web statis yang utuh.
- Menguji performa, legibilitas, dan respon tampilan web di berbagai browser (*cross-browser testing*).
- Mempublikasikan (*deploy*) website statis ke layanan hosting gratis (seperti GitHub).
