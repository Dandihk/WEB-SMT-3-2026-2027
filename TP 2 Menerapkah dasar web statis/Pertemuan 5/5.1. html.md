## A. Apa Itu HTML? (Analogi Sederhana)

Bayangkan Anda sedang membuat sebuah **Rumah** atau **Tubuh Manusia**:

```text
  +-------------------------------------------------------+
  |  HTML        = Kerangka / Tulang (Struktur Dasar)     |
  |  CSS         = Cat / Baju / Warna (Tampilan & Estetika) |
  |  JavaScript  = Otot / Saraf (Perilaku & Interaksi)    |
  +-------------------------------------------------------+
```

1. **HTML (HyperText Markup Language)** adalah **tulang punggung** atau kerangka dari setiap halaman web di internet. Tanpa HTML, tidak ada teks, gambar, tombol, atau tabel yang bisa ditampilkan di layar browser (Google Chrome, Edge, Safari).
2. **HyperText**: Teks yang berfungsi sebagai link/pintas penghubung ke halaman lain.
3. **Markup**: Kode penanda berupa **tag** (contoh: `<p>`, `<h1>`) yang memberi tahu browser bagaimana suatu teks atau media harus ditampilkan.

> [!NOTE]
> **Catatan Penting:** HTML **bukan** bahasa pemrograman (seperti C++, Python, atau Java), melainkan **bahasa penanda (*markup language*)** untuk menyusun struktur dokumen web.

## B. Anatomi Kode HTML: Tag, Elemen, dan Atribut

Setiap kode HTML dibentuk dari 3 komponen utama:

```html
  <p class="deskripsi">Selamat Datang di Web SMK TJKT!</p>
  | |                 |                                |
  | +-- Tag Pembuka   +-- Konten (Isi Teks)            +-- Tag Penutup
  +---- Atribut (class)
```

1. **Tag Pembuka (`<tag>`):** Menandai awal dari suatu elemen HTML (contoh: `<p>`).
2. **Tag Penutup (`</tag>`):** Menandai akhir dari suatu elemen, diawali tanda garis miring `/` (contoh: `</p>`).
3. **Konten:** Teks, gambar, atau elemen lain yang berada di dalam tag.
4. **Elemen:** Gabungan utuh dari tag pembuka, konten, hingga tag penutup.
5. **Atribut (`key="value"`):** Informasi tambahan yang disisipkan di dalam tag pembuka untuk mengatur sifat elemen (contoh: `class`, `id`, `src`, `href`).

### Contoh Tag Berpasangan vs Self-Closing Tag:
* **Tag Berpasangan (Memiliki Tag Penutup):**
  - `<h1>Judul Halaman</h1>`
  - `<p>Ini paragraf teks.</p>`
  - `<button>Klik Saya</button>`
* **Self-Closing Tag (Tanpa Tag Penutup / Berdiri Sendiri):**
  - `<br>` : Garis baru (*break line*)
  - `<hr>` : Garis pembatas horizontal
  - `<img src="logo.png">` : Memanggil gambar

## C. Struktur Wajib Dokumen HTML5

Setiap file HTML yang valid wajib memiliki struktur dasar sebagai berikut:

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Website Pertamaku - SMK TJKT</title>
</head>
<body>

    <h1>Selamat Datang di Website Saya</h1>
    <p>Ini adalah halaman web statis pertama yang saya buat menggunakan HTML.</p>

</body>
</html>
```

### Penjelasan Bagian Struktur Utama:

| Komponen / Tag | Analogi & Fungsi Utama |
| :--- | :--- |
| **`<!DOCTYPE html>`** | Deklarasi wajib di baris pertama untuk memberi tahu browser bahwa dokumen ini menggunakan standar versi **HTML5**. |
| **`<html lang="id">`** | Tag pembungkus utama seluruh dokumen HTML. Atribut `lang="id"` menandakan bahasa utama web adalah Bahasa Indonesia. |
| **`<head>`** | **Bagian Belakang Layar (Dapur Web).** Berisi informasi meta (*metadata*), judul tab browser, link file CSS, dan pustaka font. Konten di dalam `<head>` tidak tampil di dalam halaman web. |
| **`<title>`** | Menentukan judul yang muncul pada **Tab Browser**. |
| **`<body>`** | **Bagian Panggung Utama (Layar Tampilan).** Tempat di mana seluruh isi teks, gambar, video, tombol, dan tabel diletakkan agar dapat dilihat oleh pengunjung web. |

## D. Tag-Tag Dasar HTML yang Wajib Dikuasai

Berikut adalah daftar tag dasar yang paling sering digunakan dalam pembuatan web statis:

### 1. Heading (Judul Utama & Sub-Judul)
HTML menyediakan 6 tingkat hirarki judul, mulai dari `<h1>` (terbesar & paling penting) hingga `<h6>` (terkecil).

```html
<h1>Heading 1 - Judul Utama Halaman</h1>
<h2>Heading 2 - Sub Judul Bab</h2>
<h3>Heading 3 - Sub-sub Judul</h3>
<h4>Heading 4 - Judul Kecil</h4>
<h5>Heading 5 - Judul Lebih Kecil</h5>
<h6>Heading 6 - Judul Terkecil</h6>
```

> [!TIP]
> **Aturan SEO & Desain:** Gunakan tag `<h1>` **hanya 1 kali** dalam satu halaman web sebagai judul utama topik.

---

### 2. Paragraf & Format Teks

```html
<!-- Paragraf Teks -->
<p>HTML sangat mudah dipahami jika kita rajin berlatih setiap hari.</p>

<!-- Format Teks -->
<p>
  <b>Teks Tebal (Bold)</b> atau <strong>Teks Penting</strong><br>
  <i>Teks Miring (Italic)</i> atau <em>Teks Penekanan</em><br>
  <u>Teks Bergaris Bawah (Underline)</u><br>
  <mark>Teks Stabilo (Highlight)</mark>
</p>
```

---

### 3. Gambar (`<img>`)
Digunakan untuk menampilkan gambar di halaman web.

```html
<img src="gambar-sekolah.jpg" alt="Foto Gedung SMK TJKT" width="400">
```

* **`src` (source):** Alamat/path file gambar (lokal atau URL internet).
* **`alt` (alternative text):** Teks pengganti yang muncul jika gambar gagal di-load atau dibaca oleh *screen reader* (aksesibilitas).
* **`width` / `height`:** Mengatur ukuran lebar/tinggi gambar.

---

### 4. Link / Tautan (`<a>`)
Digunakan untuk berpindah halaman atau membuka website lain (*Hyperlink*).

```html
<!-- Link Internal (Ke halaman lain di folder yang sama) -->
<a href="tentang.html">Buka Halaman Tentang Kami</a>

<!-- Link Eksternal (Membuka tab baru di browser) -->
<a href="https://google.com" target="_blank">Cari di Google</a>
```

---

### 5. List / Daftar (`<ul>`, `<ol>`, `<li>`)
Digunakan untuk menyusun daftar informasi secara terurut atau tidak terurut.

#### A. Unordered List (Daftar Peluru / Bullet Points):
```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

#### B. Ordered List (Daftar Angka / Nomor Terurut):
```html
<ol>
    <li>Buka VS Code</li>
    <li>Buat File index.html</li>
    <li>Jalankan di Browser</li>
</ol>
```

---

### 6. Pembungkus Konten (`<div>` dan `<span>`)
Digunakan untuk mengelompokkan elemen-elemen HTML agar mudah diberi gaya CSS nantinya.

* **`<div>` (Block Element):** Pembungkus besar yang memakan 1 baris penuh layar.
* **`<span>` (Inline Element):** Pembungkus kecil yang berada di dalam baris teks.

```html
<div class="kartu-profil">
    <h2>Nama: Budi Santoso</h2>
    <p>Status: Siswa <span style="color: green;">Aktif</span></p>
</div>
```

## E. Langkah Praktik: Membuat File HTML Pertama Anda

Mari kita praktikkannya langsung menggunakan **Visual Studio Code (VS Code)**:

1. **Buka VS Code** di laptop/komputer Anda.
2. Buat folder baru di laptop Anda dengan nama: `latihan-html`.
3. Di dalam VS Code, buka folder tersebut (`File` > `Open Folder`).
4. Buat file baru dengan nama **`index.html`** *(Ingat: gunakan huruf kecil semua tanpa spasi!)*.
5. Ketik tanda seru `!` lalu tekan tombol **`TAB`** atau **`Enter`** pada keyboard. VS Code akan otomatis membuatkan struktur dasar HTML5.
6. Ubah isi file `index.html` menjadi seperti kode berikut:

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Halaman Web Pertama - SMK TJKT</title>
</head>
<body>

    <h1>Halo Dunia! 👋</h1>
    <p>Selamat datang di kelas Pemrograman Web SMK TJKT.</p>
    
    <hr>
    
    <h2>Hobi Saya</h2>
    <ul>
        <li>Koding Web</li>
        <li>Bermain Game</li>
        <li>Membaca Buku</li>
    </ul>

    <p>Kunjungi website sekolah: <a href="https://smkthpt.sch.id" target="_blank">Website SMK</a></p>

</body>
</html>
```

7. Simpan file (`Ctrl + S`).
8. Klik ganda (*double click*) file `index.html` dari File Explorer laptop Anda untuk membukanya di browser (Google Chrome).
9. **Selamat!** Anda telah berhasil membuat web statis pertama Anda! 🎉

## F. Rangkuman Materi

1. **HTML** adalah bahasa penanda (*markup language*) untuk membuat struktur dan kerangka halaman web.
2. File HTML disimpan dengan ekstensi **`.html`**.
3. Struktur dasar HTML terdiri dari `<!DOCTYPE html>`, `<html>`, `<head>` (informasi belakang layar), dan `<body>` (tampilan visual).
4. Komponen HTML dibangun dari **Tag Pembuka**, **Konten**, **Tag Penutup**, dan **Atribut**.
5. Elemen **Heading** (`<h1>`-`<h6>`), **Paragraf** (`<p>`), **Gambar** (`<img>`), **Link** (`<a>`), dan **List** (`<ul>`/`<ol>`) adalah pondasi utama dalam pembuatan web statis.
