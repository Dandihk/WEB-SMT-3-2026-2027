## A. Apa Itu JavaScript? (Analogi Sederhana)

Jika kita ibaratkan sebuah **Mobil**:
* **HTML** adalah **bodi dan rangka mobil** (pintu, jendela, roda).
* **CSS** adalah **cat warna merah dan jok kulit** (membuat mobil keren).
* **JavaScript** adalah **mesin, klakson, dan tombol power** (membuat mobil bisa berjalan dan merespons saat tombol ditekan).

Tanpa JavaScript, halaman web seperti kertas koran yang diam. Dengan JavaScript, web bisa merespons saat tombol diklik, membuka pop-up, atau mengubah warna tema (*Dark Mode*).

## B. Cara Menyambungkan JavaScript ke HTML

1. Buat file baru di folder proyek Anda dengan nama: **`script.js`**.
2. Panggil file `script.js` di baris paling bawah tepat sebelum tag penutup `</body>` pada file **`index.html`**:

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Web Interaktif</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1 id="judul">Selamat Datang!</h1>
    <button id="tombol-sapa">Klik Saya</button>

    <!-- Menyambungkan File JavaScript -->
    <script src="script.js"></script>
</body>
</html>
```

## C. Dasar Sintaks JavaScript: Variabel & Pesan

### 1. Variabel (Wadah Penyimpan Data)
Variabel digunakan untuk menyimpan data sementara.
* Use `let` jika nilainya **bisa berubah**.
* Use `const` jika nilainya **tetap / tidak boleh berubah**.

```javascript
let namaSiswa = "Budi";
const umur = 17;

// Menampilkan pesan rahasia di Console Browser (F12)
console.log(namaSiswa);
console.log(umur);
```

---

## D. Manipulasi DOM (Mengubah HTML Menggunakan JS)

**DOM (Document Object Model)** adalah cara JavaScript membaca dan mengubah isi atau tampilan elemen HTML.

### 2 Langkah Utama Manipulasi DOM:
1. **Ambil Elemennya** berdasarkan `id` atau `class`.
2. **Ubah Isinya** atau **Ubah Gayanya (CSS)**.

```javascript
// 1. Ambil elemen yang punya id="judul"
let judulElemen = document.getElementById("judul");

// 2. Ubah isi teksnya
judulElemen.textContent = "Halo, Selamat Belajar JavaScript!";

// 3. Ubah warna teksnya via JS
judulElemen.style.color = "red";
```

---

## E. Event Listener (Merespons Klik Tombol)

Event Listener digunakan agar JavaScript tahu kapan pengguna melakukan aksi (seperti mengklik tombol).

```javascript
// 1. Ambil tombol berdasarkan ID
let tombolSapa = document.getElementById("tombol-sapa");
let judul = document.getElementById("judul");

// 2. Berikan aksi saat tombol DIKLIK
tombolSapa.addEventListener("click", function() {
    // Tampilkan pesan pop-up
    alert("Halo! Terima kasih sudah mengklik tombol.");
    
    // Ubah teks judul
    judul.textContent = "Tombol Berhasil Diklik! 🎉";
    judul.style.color = "green";
});
```

## F. Latihan Praktik: Fitur Ubah Warna Tema (Dark Mode Simple)

Mari buat fitur **Dark Mode (Tema Gelap)** sederhana!

### 1. Kode HTML (`index.html`):
```html
<button id="tombol-tema">🌙 Ubah Ke Mode Gelap</button>
```

### 2. Kode CSS (`style.css`):
```css
/* Class khusus untuk tema gelap */
.mode-gelap {
    background-color: #1a1a1a;
    color: #ffffff;
}
```

### 3. Kode JS (`script.js`):
```javascript
let tombolTema = document.getElementById("tombol-tema");

tombolTema.addEventListener("click", function() {
    // Tambah/Hapus class 'mode-gelap' pada <body> secara bergantian (toggle)
    document.body.classList.toggle("mode-gelap");
    
    // Cek apakah mode gelap aktif
    if (document.body.classList.contains("mode-gelap")) {
        tombolTema.textContent = "☀️ Ubah Ke Mode Terang";
    } else {
        tombolTema.textContent = "🌙 Ubah Ke Mode Gelap";
    }
});
```

## G. Rangkuman & Uji Pemahaman

1. **JavaScript** digunakan untuk memberi interaktivitas pada halaman web.
2. File JS disambungkan menggunakan `<script src="script.js"></script>` di akhir tag `</body>`.
3. `document.getElementById()` digunakan untuk mengambil elemen HTML berdasarkan `id`.
4. `addEventListener("click", function() { ... })` digunakan untuk menjalankan kode saat tombol diklik.
